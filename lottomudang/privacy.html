로또무당 (Lotto Mudang)

개인정보처리방침

시행일: 2026년 04월 01일

제1조 (개요)

로또무당(이하 "앱" 또는 "서비스")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 개인정보처리방침은 앱이 수집하는 개인정보의 항목, 수집·이용 목적, 보유 기간, 제3자 제공 내역 및 이용자의 권리를 안내합니다.

본 방침은 앱 업데이트 또는 법령 변경에 따라 개정될 수 있으며, 변경 시 앱 내 공지 또는 본 페이지를 통해 고지합니다.

제2조 (수집하는 개인정보 항목 및 목적)

수집 항목 수집 목적 수집 방법
기기 고유 식별자(UUID) 회원 식별, 서비스 개인화 앱 자동 생성·저장
FCM 토큰 푸시 알림 전송 Firebase Cloud Messaging 자동 수집
손바닥 이미지 AI 손금 분석 이용자 직접 촬영·업로드
위치 정보(GPS) 행운 명당 지도 서비스 제공 이용자 권한 허용 후 수집
광고 식별자(GAID) 맞춤 광고 제공(Google AdMob) Google AdMob SDK 자동 수집
앱 사용 로그·이벤트 서비스 개선, 통계 분석 Firebase Analytics 자동 수집
오류·충돌 로그 앱 안정성 개선 Firebase Crashlytics 자동 수집
운세 입력 데이터(생년월일, 이름 등) AI 운세 결과 생성 이용자 직접 입력

손바닥 이미지는 분석 후 서버에 저장되지 않으며, AI 분석 처리 완료 즉시 삭제됩니다.

제3조 (개인정보 보유 및 이용 기간)

항목 보유 기간
기기 UUID, FCM 토큰 서비스 이용 기간 동안 (탈퇴·삭제 요청 시 즉시 파기)
손바닥 이미지 분석 완료 즉시 삭제
위치 정보 세션 종료 시 즉시 파기 (서버 저장 없음)
운세 입력 데이터 결과 생성 후 즉시 파기 (서버 저장 없음)
앱 로그·통계 수집일로부터 최대 26개월 (Google 정책 준수)
오류 로그 수집일로부터 최대 90일 (Firebase Crashlytics 정책)

제4조 (개인정보의 제3자 제공)

앱은 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만, 아래의 경우에는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령의 규정에 의거하거나 수사기관의 요청이 있는 경우

제5조 (개인정보 처리 위탁 및 외부 서비스)

앱은 서비스 운영을 위해 아래 외부 서비스를 이용하며, 해당 서비스의 개인정보처리방침이 적용됩니다.

서비스 사업자 처리 목적
Firebase (Auth, Firestore, Analytics, Crashlytics, FCM) Google LLC 인증, 데이터 저장, 분석, 오류 수집, 푸시 알림
Google AdMob Google LLC 광고 제공, 광고 식별자 수집
Gemini API Google LLC AI 운세 분석 결과 생성
Google ML Kit Google LLC 손 이미지 온디바이스 분석

각 서비스의 개인정보처리방침은 Google 개인정보처리방침(https://policies.google.com/privacy)을 참고하시기 바랍니다.

제6조 (앱 접근 권한 안내)

권한 필수/선택 사용 목적
카메라 선택 손금 분석을 위한 손바닥 촬영
사진/미디어 접근 선택 갤러리에서 손바닥 이미지 선택
위치(GPS) 선택 주변 행운 명당 지도 표시
알림 선택 행운 운세 푸시 알림 수신

선택 권한을 허용하지 않아도 해당 기능을 제외한 나머지 서비스 이용이 가능합니다.

제7조 (이용자의 권리)

이용자는 언제든지 다음과 같은 권리를 행사할 수 있습니다.

  • 개인정보 열람 요청
  • 개인정보 정정·삭제 요청
  • 개인정보 처리 정지 요청
  • 광고 식별자 재설정 또는 광고 맞춤화 거부 (기기 설정에서 변경 가능)

권리 행사는 아래 연락처를 통해 요청하실 수 있으며, 요청 후 10영업일 이내에 조치합니다.

제8조 (자동 수집 항목의 거부)

  • 광고 식별자(GAID): Android 설정 → 개인정보 보호 → 광고에서 "광고 개인최적화 해제" 또는 광고 ID 재설정 가능
  • Firebase Analytics: 앱 설정 내 데이터 수집 동의 철회 가능 (향후 기능 제공 예정)

제9조 (아동의 개인정보 보호)

앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 이용자의 개인정보가 수집된 사실을 인지한 경우, 해당 정보를 즉시 삭제합니다.
