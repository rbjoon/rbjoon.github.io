로또무당 (Lotto Mudang)

개인정보처리방침

시행일: 2026년 05월 11일  |  이전 시행일: 2026년 04월 01일

제1조 (개요)

로또무당(이하 "앱" 또는 "서비스")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」(2023년 개정 포함) 및 관련 법령을 준수합니다. 본 개인정보처리방침은 앱이 수집하는 개인정보의 항목, 수집·이용 목적, 보유 기간, 제3자 제공 내역 및 이용자의 권리를 안내합니다.

본 방침은 앱 업데이트 또는 법령 변경에 따라 개정될 수 있으며, 변경 시 앱 내 공지 또는 본 페이지를 통해 고지합니다.

제2조 (수집하는 개인정보 항목 및 목적)

수집 항목 수집 목적 수집 방법
기기 고유 식별자(익명 UID) 서비스 이용 기록 연속성 유지, 운세 결과 일관성 보장 Firebase Anonymous Auth 자동 생성
FCM 토큰 행운 운세·로또 결과 푸시 알림 전송 Firebase Cloud Messaging 자동 수집
손바닥 이미지 AI 손금 분석 (기기 내 온디바이스 처리 후 즉시 파기) 이용자 직접 촬영 또는 갤러리 선택
위치 정보(GPS 좌표) 주변 행운 명당(로또 판매점) 지도 표시 이용자 권한 허용 후 수집, 카카오 로컬 API 서버로 전송
꿈 내용 텍스트 AI 꿈 해몽 결과 생성 (Firebase Cloud Functions 경유) 이용자 직접 입력

광고 식별자 (Android: GAID, iOS: IDFA) 맞춤형 광고 제공(Google AdMob) Google AdMob SDK 자동 수집 (iOS는 ATT 동의 후)
앱 사용 로그·이벤트 서비스 개선, 이용 패턴 통계 분석 Firebase Analytics 자동 수집
오류·충돌 로그 앱 안정성 개선 Firebase Crashlytics 자동 수집

손바닥 이미지는 Google ML Kit를 통해 기기 내에서만 처리되며, 외부 서버로 전송되지 않습니다. 분석 완료 즉시 메모리에서 삭제됩니다.

생년월일은 별자리 계산에만 사용되며 서버에 저장되지 않습니다. 이름은 수집하지 않습니다.

위치 정보(GPS 좌표)는 명당 지도 기능 사용 시에만 수집되며, 카카오 로컬 API 서버로 전달되어 주변 로또 판매점 검색에 사용됩니다. 서비스 자체 서버에는 저장되지 않습니다.

제4조 (개인정보의 제3자 제공)

앱은 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만, 아래의 경우에는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령의 규정에 의거하거나 수사기관의 적법한 요청이 있는 경우

제5조 (개인정보 처리 위탁 및 외부 서비스)

앱은 서비스 운영을 위해 아래 외부 서비스를 이용하며, 각 서비스의 개인정보처리방침이 함께 적용됩니다.

선택 권한을 허용하지 않아도 해당 기능을 제외한 나머지 서비스를 이용할 수 있습니다.

제7조 (이용자의 권리)

이용자는 언제든지 다음과 같은 권리를 행사할 수 있습니다.

  • 열람권: 자신의 개인정보 처리 현황 열람 요청
  • 정정·삭제권: 잘못된 개인정보의 정정 또는 삭제 요청
  • 처리 정지권: 개인정보 처리 정지 요청
  • 이동권: 자신의 개인정보를 체계적으로 제공받거나 다른 기관에 이전 요청 (개인정보보호법 제35조의2)
  • 자동화 결정 설명 요구권: AI가 생성한 운세·손금·해몽 결과 등 자동화된 결정에 대한 설명 요구 및 이의 제기 (개인정보보호법 제37조의2)
  • 광고 식별자 재설정/거부:
    • Android: 설정 → 개인정보 보호 → 광고 → 광고 ID 삭제 또는 맞춤 광고 해제
    • iOS: 설정 → 개인정보 보호 및 보안 → 추적 → 앱이 추적을 요청하도록 허용 해제

권리 행사는 아래 연락처를 통해 요청하실 수 있으며, 요청 후 10영업일 이내에 조치합니다.

제8조 (자동화된 결정에 관한 사항)

앱이 제공하는 로또 번호 추천, AI 운세, 손금 분석, 꿈 해몽 등은 알고리즘 또는 AI 모델에 의해 자동으로 생성되는 결과입니다. 이용자는 해당 결과에 대해 다음 권리를 행사할 수 있습니다.

  • 결과 생성에 적용된 기준 및 방식에 대한 설명 요구
  • 결과에 대한 이의 제기 (아래 연락처로 요청)

단, 본 서비스의 AI 결과물은 오락·참고 목적으로만 제공되며 법적 효력이 없습니다.

제9조 (아동의 개인정보 보호)

앱은 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 이용자의 개인정보가 수집된 사실을 인지한 경우, 해당 정보를 즉시 삭제합니다.
